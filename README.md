# SnapStash

Lightweight tool to save screenshots, harnessing the power of AI agents to tag and organise them for later retrieval.

## Installation
1) Run snap.py to start background listener which triggers SnapStash on prtscn button press. (Warning: this will suppress existing functionality mapped to prtscn).

2) Optional: Run install-startup.ps1 to run snap.py on startup.

## Uninstall
1) Run uninstall-startup.ps1 to remove snap.py background process from startup.
